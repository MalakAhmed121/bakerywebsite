# 🥐 Bakery Website

A simple front-end bakery website built using **HTML and CSS**.

This project was developed as my part of a larger team project. My contribution focused on designing and developing the bakery website pages and creating a simple user interface for displaying different bakery products.

## ✨ Features

- 🏠 Bakery homepage
- 🥖 Bread page
- 🥐 Croissants page
- 🍩 Donuts page
- 🍪 Cookies page
- 🍰 Cinnamon page
- 🧁 Macarons page
- Responsive and simple user interface
- Product images and visual design using CSS

## 🛠️ Technologies Used

- HTML
- CSS
